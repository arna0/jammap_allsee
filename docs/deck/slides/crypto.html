Why it runs on Solana

Records no one can edit

Each confirmed incident keeps the phones' signatures on-chain. An insurer can check it without trusting us.

Paid coverage

Phones that report confirmed incidents earn tokens, so coverage grows where interference happens.

Machine payments

Drones pay per request in USDC through x402. Fees are a fraction of a cent.

07

Why a blockchain? Three reasons. First, records nobody can edit, including us: every confirmed incident on Solana carries the signatures of the phones that saw it, which matters when an insurer needs to know whether GPS failed at a given time and place. Second, we pay phones in tokens for confirmed reports, so coverage grows exactly where the problem is. Third, machines can pay machines: a drone's software pays one cent per query in USDC, with fees far below a cent, which only works on a fast, cheap chain.
