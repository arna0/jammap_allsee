How JamMap works

01

Detect

The app checks the satellite signal every second and flags jamming or spoofing.

02

Sign

The phone signs a short report with its own key. It needs no wallet and no SOL.

03

Confirm

A Solana program checks every signature and confirms the incident once 3 different phones agree.

04

Sell

Drone and fleet software pays 1 cent in USDC per query. No account, no API key.

The app only listens. It never transmits anything.

05

Four steps. One: the phone checks the signal every second. Two: when it sees jamming or spoofing, it signs a short report with its own key. The phone doesn't need a wallet or any SOL; our relayer pays the fee. Three: a program on Solana checks that signature itself, so even we can't fake a report, and it only confirms an incident when three different phones see it. Four: drone and fleet software buys the data per request, one cent in USDC, using the x402 payment standard. And to be clear: the app only listens, it never transmits.
