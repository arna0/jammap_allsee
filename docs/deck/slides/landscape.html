How does this compare? Flight-tracker maps use aircraft data, so they don't see the ground. Satellite radio monitoring exists but is expensive and mostly sold to governments. GEODNET and Onocoy run fixed base stations for precise positioning, not interference mapping. JamMap uses phones people already carry, works at ground level, and every confirmed incident can be checked on Solana. We also searched over 8,000 past Colosseum hackathon projects and found no one doing this with phones.
