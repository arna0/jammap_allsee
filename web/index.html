    Route check

    Check a drone flight or a truck route against interference reported in the last 24 hours. Click the map to set the start and end points.

    Data API

    Pay per request in USDC on Solana using x402. No account and no API key: the client receives 402 Payment Required, signs a USDC transfer and repeats the request with an X-PAYMENT header.

    EndpointPrice
    GET /v1/risk?lat&lon&radius_kmRisk score, incidents and estimated source locations around a point$0.01
    GET /v1/route?from&to&corridor_kmInterference exposure along a straight route$0.01
    GET /v1/mapZone-level public mapFree

    Example

    $ curl -i "$JAMMAP/v1/risk?lat=42.32&lon=69.62"
HTTP/1.1 402 Payment Required
{"accepts":[{"scheme":"exact","network":"solana-devnet",
  "maxAmountRequired":"10000","asset":"USDC", ...}]}

$ curl -H "X-PAYMENT: <signed USDC transfer>" ...
HTTP/1.1 200 OK
{"risk":{"score":82,"level":"high"},"incidents":[...]}

    Demo mode: sensors are simulated and payments are not settled on-chain.
